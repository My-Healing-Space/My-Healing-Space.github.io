# Website Build Prompt: My Healing Space

## Project Overview
Build a professional, mobile-responsive website for "My Healing Space" - a counseling and wellness service in Sri Lanka. The website should convey warmth, safety, and professionalism while being fully functional across all devices.

---

## Technical Requirements

### Core Technologies
- **HTML5** - Semantic markup
- **Tailwind CSS** - For styling and responsive design
- **Vanilla JavaScript** - For animations and interactivity
- **Mobile-first approach** - Ensure perfect responsiveness on all screen sizes

### Performance Requirements
- Smooth scroll animations
- Fade-in effects on scroll
- Hamburger menu for mobile navigation
- Fast loading times
- Optimized images

---

## Design Specifications

### Color Palette
- **Primary Colors:**
  - Soft teal/turquoise (#4A9B9B or similar calming blue-green)
  - Warm white/cream (#FEFEFE, #F9F9F9)
  - Soft gray for text (#4A5568, #718096)
  
- **Accent Colors:**
  - Gentle purple/lavender for highlights
  - Muted gold/amber for CTA buttons
  
- **Background:**
  - Light cream/off-white for main backgrounds
  - Subtle gradient overlays for hero sections

### Typography
- **Headings:** Clean, modern sans-serif (e.g., Inter, Poppins, or Montserrat)
- **Body Text:** Easy-to-read sans-serif (e.g., Open Sans, Lato)
- **Font Sizes:**
  - Hero heading: 3xl-6xl (responsive)
  - Section headings: 2xl-4xl
  - Body: base to lg
  - Mobile: Scale down appropriately

### Design Style
- Clean, minimalist layout
- Ample white space
- Soft shadows and rounded corners
- Calming, professional aesthetic
- Empathetic and welcoming tone

## Animation & Interaction Requirements

### Scroll Animations
1. **Fade-in on scroll:** Apply to all major sections
2. **Slide-in from left/right:** Alternate for section content
3. **Counter animations:** If displaying statistics
4. **Parallax effect:** Hero section background

### Hover Effects
1. **Navigation links:** Underline animation
2. **Buttons:** Scale slightly, shadow increase
3. **Service cards:** Lift effect with shadow
4. **Social icons:** Color change or rotation

### Mobile Menu
1. **Hamburger icon:** Three-line menu that transforms to X
2. **Menu slide:** Slide from right or overlay with fade
3. **Close on link click**
4. **Smooth transitions:** 300-400ms

### Loading Animations
1. **Page load:** Subtle fade-in
2. **Image lazy loading:** Blur-up or skeleton screens
3. **Form submission:** Loading spinner

## Accessibility Requirements

1. **Keyboard navigation:** All interactive elements accessible via keyboard
2. **Screen reader support:** Proper ARIA labels and semantic HTML
3. **Color contrast:** WCAG AA compliance minimum
4. **Focus indicators:** Visible focus states
5. **Alt text:** All images have descriptive alt text
6. **Form labels:** Properly associated with inputs

---

## Performance Optimization

1. **Image optimization:**
   - WebP format with fallbacks
   - Lazy loading
   - Responsive images (srcset)
   - Proper sizing

2. **CSS optimization:**
   - Minimize unused Tailwind classes (use purge/content config)
   - Critical CSS inline

3. **JavaScript:**
   - Defer non-critical scripts
   - Minify in production
   - Use passive event listeners

4. **Loading strategy:**
   - Above-the-fold content prioritized
   - Async/defer for third-party scripts
